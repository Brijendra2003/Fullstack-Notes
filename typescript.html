Why TypeScript? Basic

TypeScript is a superset of JavaScript: every JS file is already valid TS. It adds static types, which are checked before your code runs. Browsers can't run TS, so it is compiled to plain JavaScript first.

Union & literal types Basic

A union (A | B) means "either A or B". A literal type allows only exact values.

type Status = "idle" | "loading" | "success" | "error"
"idle""loading""success""error" "done""pending"42

Only the highlighted values are allowed. Typos like "sucess" are caught right away.

Generics Intermediate

Generics are type parameters. They let one function or type work with many types without losing type information.

Labelled boxBox<T> is a box whose label you fill in later. Box<Shoe> holds shoes and Box<Book> holds books. It's the same box design, and you always know what's inside.
T flows from input to output
first([1,2,3])T = number
function first<T>(arr: T[]): T
returns number

Mapped types Advanced

A mapped type loops over the keys of a type and builds a new one. This is how Partial and Readonly are built.

{ [K in keyof T]: … }
{ name: string; age: number }
for each key K
K → () => T[K]
result
{ getName(): string; getAge(): number }

Conditional types & infer Advanced

The syntax is T extends U ? X : Y, which works like a ternary operator for types. With infer you can pull a type out of another type.
